================================================================================
  WHAT HAPPENS DURING PAYMENT
================================================================================

FRONTEND (Browser):
1. User clicks "PAY & PUBLISH"
2. Calls /api/create-order
3. Receives orderId + keyId from backend
4. Opens Razorpay modal with orderId
5. User fills card details in modal
6. Clicks "Pay"
7. Razorpay returns: razorpay_order_id, razorpay_payment_id, razorpay_signature
8. Sends all three to /api/verify-payment
9. Shows success or error

BACKEND (Node.js):
1. Receives request to /api/create-order
2. Calls rzp.orders.create() with amount, currency, receipt
3. Razorpay API creates order, returns order_id
4. Stores order details in-memory with orderId
5. Returns orderId + keyId to frontend

6. Receives request to /api/verify-payment
7. Validates order exists in-memory
8. **CRITICAL**: Computes HMAC-SHA256(orderId|paymentId, SECRET)
9. Compares computed signature with razorpay_signature
10. If match: Publish invitation (JSON file), return inviteId
11. If mismatch: Return error 400

RAZORPAY (External):
• User enters card → Razorpay processes payment
• Returns payment_id + signature
• Frontend forwards to our backend for verification
• We verify the signature matches (ensures Razorpay really processed it)

   • Account → Activate

   RAZORPAY_KEY_ID=rzp_live_XXXXXXXXXXXXXXXX
   RAZORPAY_KEY_SECRET=XXXXXXXXXXXXXXXX
   NODE_ENV=production

3. DEPLOY
   • Use deployment platform (Vercel, Heroku, AWS, etc.)
   • Set environment variables in platform settings
   • Never hardcode credentials in code

4. HTTPS REQUIRED
   • Razorpay requires secure (HTTPS) connections
   • Use SSL certificate for production domain

5. TEST BEFORE LAUNCH
   • Test payments in live mode with Razorpay test cards
